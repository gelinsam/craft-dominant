# Launch intelligence

Protected /api/intelligence/launches derives descriptive edition summaries from current stored orders and private Meta snapshots beside DB_PATH. /launches displays them without changing the root pacing view. Owner-confirmed first years are explicit; NYC is a relaunch. Exact event names prevent mixing coffee with other festival categories. Candidate campaign names and delivery windows remain provisional attribution.

Existing MetaAdsSync transport and the campaign maintenance cycle provide read-only refreshes. Prior daily observations survive missing fields and failed collection. No new scheduling framework, model or ad-write path is introduced. dlt was evaluated for extraction; reuse of the existing transport avoids a second credential and state pipeline. PyMC-Marketing remains a possible later analysis layer, after comparable evidence exists.

Private files are not shipped with the repository. Seed coffee-launch-history.json and nyc-launch-history.json from authorized read-only collection. The daily incremental refresh does not fabricate missing historical observations. Current creatives are not historical versions. Gross revenue is not incremental ROAS. Missing campaign evidence is unknown spend. Customer identities are never included in the endpoint.
